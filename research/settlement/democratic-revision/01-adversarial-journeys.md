# Democratic revision: authored adversarial journeys

*Design 83 boundary reasoning, not verdicts, observations or ready operations.*

| Situation | Reference consequence and retained failure |
|---|---|
| An existing protected class cannot register because only one inaccessible credential is accepted | First seek effective ordinary relief. If amendment really needed, RR permits narrow early restoration only under old-law review/full vote and usable pre-call schedule. Party polling is no veto; actual capacity unknown. |
| A new proposal lowers voting age beyond the existing protected entitlement | Prospective public amendment remains available. Calling it inclusion does not establish RR restoration of an existing right. |
| Cabinet combines accessible ballots with four new friendly judges | RR03 bars the packing exception. Only approved express severability can separate valid access; otherwise delayed route or new text/authorization. No executive scissors. |
| The repair exception is proposed for the first time | The predecessor amendment/delay route applies to its own introduction; it cannot authorize its own earlier start. Legitimate first founding differs. |
| A restoration would enfranchise people who are not presently entitled under old law | They cannot count themselves into the initiating denominator or ratifying ballot. Existing actual judgments count; illegitimacy of that old settlement remains a real constituent objection. |
| A snap election is called during deliberation | RR cannot postpone the poll. Only actual binding judgment enforcement may restore an existing right in the called contest; a new amendment gets no shortcut. |
| A formation-failure repeat poll follows an inconclusive first poll | It remains part of the protected immediate-succession sequence, not a way to activate a favored new voting rule between attempts. |
| Every lawful reviewer has a direct conflict | No approval presumed and no minister-appointed replacement tribunal. Individual ordinary remedies may remain; the structural repair can fail. |
| A sponsor submits a million genuinely distinct useful arguments | Finite formal intake/examination, no claim all were preserved/read, no unlimited invoice. Actual humans/affected agenda choose finite issues; message-lottery manipulation cannot buy more chances. |
| A sole speaker demonstrates a consequence the text summary loses | Assisted reference records lost meaning, another interpretation and correction route. If unselected for capacity it remains unexamined, not duplicate/refuted. Court relief remains possible for actual rights. |
| A collective uses one shared study to express different values | Shared source disclosed; distinct people and incompatible reasons preserved. Neither source independence nor a political mandate is inferred from AI repetition. |
| The only safe sample frame excludes undocumented affected people | Confidential assisted alternatives/outreach required; disclose coverage failure. If indispensable coverage cannot be delivered, narrow/defer rather than claim fourteen agenda setters represent everyone. |
| All thirty slots are filled but an omitted credible risk makes action unlawful | Filled slots are no legality certificate. Narrow/defer/correct; a competent court can stop unlawful action under its existing powers. |
| An urgent personal liberty/benefit claim arrives on closure day | Assisted accepted referral/direct court route retains its own useful-time clock; FA closure cannot reject it as policy feedback. |
| The coordinator suppresses opposition sources and its vendor supplies the reviewer | Different career supervisor/qualified replacement and direct court challenge, preserved originals/pay/receipts. Shared controllers are not independence; actual alternate can still be unavailable. |
| Day90 arrives with no supported hearing completed | Acknowledge failed process, no automatic law. Single lawful extension can reach120; after that baseline/withdrawal/narrowing/new funded cycle, subject to controlling duties. |
| A new value objection arrives after a lawful policy decision | Reasoned routing/selection status within ten days; actual merits review is distinguished and bounded. Political reconsideration stays available. Novelty alone isn't a mandatory stay; it need not masquerade as new empirical evidence. |
| The sponsor sends endless novel reopening “complaints” | FA10 distinguishes legal/process duties from discretionary new policy input. Ten-day routing is not a promise of exhaustive merits review, and unexamined status remains visible. |
| A contractor departs with protected testimony and unpaid interpreters | Named custodian receives safe records/mandates/claims; due pay and challenges survive. A signed exit clause without actual transfer is a failure. |

Each outcome follows an authored reference, not proof that a hostile cabinet,
independent court, sampling frame or receiver exists. Actual source finance,
qualified reviewer capacity, affected objections and distribution remain unknown.
