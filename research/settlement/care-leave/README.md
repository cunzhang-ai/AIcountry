# Care time is a substantive part of the country offer

Design180 · [CL01–CL24](../../country/C05/17-care-leave-and-return.md), proposed law

C05/02 and TW12 promised portable care leave; the original time settlement
expressly deferred duration/replacement/qualification/source/return. Medical
absence, equality, retirement credits and childcare did not fill that promise.
This is a whole-life independence gap, not a new nursery staffing parameter.

| Selected component | Country consequence and real cost |

| Temporary chosen-person care | Six person-normal-weeks rolling52,26calendar-week continuing-episode window; actual voluntary functional support, not marriage/household or compulsory relative care |

| Income/source |100% actual usual gross labor loss capped by independent W and covered hours, paid by existing G protection authority; actual salary reimbursement/tax/I05/EB/Y matched once |
| Services and cover | Medical recovery, public care/clinical/AS, wages and pension rights remain distinct; qualified actual replacement/private losses/paid transition are additional real duties |

Reserved time resists household/employer pressure; it can go unused, including
for a nonworking holder who never enters work within the window. Ordinary helpers
do not dilute shares. Temporary incapacity preserves personal reservations;
substantiated whole-window unavailability can release actual unspent time, with
no extra pool if an innocent holder has lawfully spent it. No forced care,
abuser permission, public private-life graph or new family licence follows.
