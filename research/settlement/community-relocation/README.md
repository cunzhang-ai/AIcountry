# Community relocation and funded host capacity

[FR09–FR13](../../country/C09/07/03-community-relocation-and-host-capacity.md)
adds a voluntary collective route to ordinary recovery. It preserves
individual choices, public approvals, host capacity and earlier rights.

1. [Observed Hawke's Bay recovery](01-hawkes-bay-recovery.md) compares
   a completed property programme with an independently scoped collective
   relocation pathway and preserves the limits of each source.
2. [Authored group and dispersed alternatives](02-group-and-dispersed-alternatives.md)
   tests effective choices, host capacity and the consequence of withdrawal.
3. [Reproduction](verify-relocation.py) checks recorded endpoints and
   the separate authored comparison.
