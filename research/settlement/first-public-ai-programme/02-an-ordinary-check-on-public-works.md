# What an ordinary public works check can already catch

*Design548 · Open calibration using published records of England's New Hospital Programme.*

**Select ordinary source reconciliation as the first funded method.**
An optional AI comparison can earn a later decision on a specific gap
after ordinary staff and fixed checks have been tried. This calibration
checks claims used to brief a public decision. It has no authority to
make engineering, safety, award or payment decisions.

The CSV pairs manually transcribed facts with true and deliberately altered
briefing claims. It uses historical vintages even when newer sources exist.
The 2025 source is unavailable to the 2023 decision. A blank observation
means that this source set provides no qualified answer. It does not assert
that interim protection does not exist. No claim here establishes how any
hospital case is operating today.

## Run the ordinary check

A qualified reader records the project or cohort, milestone, time, value,
units and source vintage. The included fixed check compares structured basis, milestone, evidence vintage and value
and reports the first reason it cannot support a claim. Reproduce the run
with `python3 research/settlement/first-public-ai-programme/check-hospital-claims.py`.
The ten cases contain three supported statements, six inconsistencies and
one insufficient-evidence result. The cases are selected by the author,
and the code verifies the labels against structured data. It does not
extract the evidence from prose or measure analysts' time or accuracy.
[Open case data](hospital-claims.csv) · [Fixed check](check-hospital-claims.py)

## What would justify paying for an AI comparison

Have the independent evaluator select fresh, lawful draft packets under
[DP78–DP83](../../country/C11/09/17-independent-public-ai-evaluation.md).
Compare competent staff with the fixed check against competent staff with
the same check and AI assistance. Start both arms from identical raw source packets and count extraction, validation and rework. Give both arms the same source vintages,
original deadlines and opportunities to request missing facts. Use
distinct comparable assignments so prior review cannot leak answers.
Record actual staff time through qualified review and rework. Include
material conflicts, valid claims, ambiguous milestones and missing evidence.
Check a later deadline or case batch before assuming a recurring gain.

The independent reviewer adjudicates source-linked findings and tracks
whether any additional, timely finding changes a feasible works decision
and reaches the responsible owner. Record misses, false alarms, delayed
work, forecast costs and actual inspection or receiving separately.
Competent people decide feasibility, lawful release and safety. A useful
finding can earn a finite next review. An equivalent ordinary result at
no greater full cost keeps the ordinary route. A slow or unsafe result
does not qualify increased reliance. This published set is open calibration.
It supplies no independent AI result, held-out score or evidence of better
care.
