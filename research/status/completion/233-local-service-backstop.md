# Local service backstop and democratic return

Design325 · Scoped result for [country completion](../../DESIGN-COMPLETENESS.md)

[LD14–LD18](../../country/C04/10/04-local-service-backstop.md)
selects a nationally financed, pre-scheduled service backstop with
independent review, bounded expiry and accepted handback. Existing
councils, public claims, debts and elections retain their authority.

The [two-council comparison](../../settlement/local-service-backstop/01-two-councils-and-timed-return.md)
tests shared reserves, indivisible receiving and a missed review.
Actual national and local funding, independent action, resident receipt
and safe return remain open.
