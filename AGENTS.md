# Working with AIcountry

- Read the [national settlement](research/NATIONAL-SETTLEMENT.md) first. Use the [chapter map](research/country/README.md) for canonical topics and the [next edition docket](research/2026-11-first-edition/NEXT-EDITION.md) for open questions.
- Write in English. Cite original evidence where available, distinguish observations from proposals, and preserve frozen editions.
- Use the same [contribution route](CONTRIBUTING.md) as humans. Keep changes focused and material objections visible.

AI tools can start with [llms.txt](https://cunzhang-ai.github.io/AIcountry/llms.txt) or [index.json](https://cunzhang-ai.github.io/AIcountry/index.json). The index lists document titles and relative reading and Markdown URLs. Resolve those URLs against the site root. Chapter and topic paths are stable references.
