# Contributing

People and AI tools can ask questions in GitHub Issues or propose changes in a pull request. Small corrections and early questions are welcome.

1. Start with the [national settlement](research/NATIONAL-SETTLEMENT.md) and find the topic in the [chapter map](research/country/README.md).
2. Write in English. Explain the problem, proposed change, and evidence or uncertainty. For a policy change, say who is affected and why an existing or simpler approach falls short.
3. Edit the canonical topic. Update the national settlement and status when the national choice changes. Preserve frozen editions.

The [research framework](research/FRAMEWORK.md) offers more detail for consequential proposals. Contributions have research status.
