# A last-source choice that admits its democratic loss

Design166 · [PS21–PS32](../../country/C06/37/06-critical-public-power-and-actual-priority.md)

**Select separately enacted standing law for scheduled public temporary backup
power.** Existing CP still excludes protected critical sources; E/NP/PS/A8 called
for prior resource law without selecting the actual hard allocation. Neither a
new commander nor a larger general CP pool fixes that value choice.

First establish actual minimum tasks/times/connection/stock and use feasible
compatible or sequential supply. If genuinely incompatible, prefer credible
imminent irreversible bodily protection, then imminent irreversible original-
record/political/remedy loss, then recoverable essential interruption. A hospital
label, existing holder, party, wealth or model score is no priority. Clinical/
UA10 will/withdrawal and actual technical/source law still constrain execution.
The generator may go to care while an actual political opportunity is lost.
This is a grave failure, not evidence that both rights were protected.

[Control, tradeoffs and limits](01-control-rivals-and-loss.md) maps qualified
existing source operation, hourly/earlier actual reassessment, independent direct
review/report24, protected sources, own-abuse routes and paid successors. No
new agency, compulsory private resource or general grid rationing is selected.

The coordinated [RX qualification](../../country/C10/01/01-rights-grounds-and-protected-functions.md)
expressly changes the former blanket alternative-access precondition for this
source alone. [ER16](../../country/C03/10/07-result-validity-and-repeat-poll.md)
adds prospective strict no-fault physical poll/source-failure and before/without-
certification determination; no guessed votes, automatic annulment or term gain.
A8/RR component-specific dates/holds and actual ER17 consequences remain;
explicit PC14/PC20/EL20 handoffs keep distinct local/question proof/repeat routes. An
unavailable/newly inapplicable court path is still failed recovery, not invented
jurisdiction. New law cannot certify its own protected-scope exception.

[Decision, sources and authored adverse arguments](https://github.com/cunzhang-ai/AIcountry/blob/edition-1/research/2026-11-critical-power-and-democratic-loss/decision-record.md)
retain protected exclusion plus actual paid redundancy, broader allocation and
distributed/common alternatives. Actual rights compatibility, full source,
independent safe operation, affected judgment and better lives remain unproved.
